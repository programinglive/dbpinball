## Known limitations

- Windows binaries are **not code-signed**. SmartScreen warns and heuristic scanners can flag unsigned binaries; verify the SHA-256 before running.
- macOS is not packaged.
- Non-MariaDB MySQL is refused for Safe Sync.
- `deterministic_phone`, `date_shift`, `amount_jitter` and `fixed` are declared but not implemented, and are refused.
- Linux install/launch was not executed on a real Linux host; WSL cannot start on the build workstation.
